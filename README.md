# ⚛️ React Project (Vite)

A front-end web project built using React and Vite, focusing on simplicity, performance, and clean logic by relying only on core React features without external UI or state management libraries.

---

## 🛠️ Technologies & Tools

- ⚛️ React.js
- ⚡ Vite
- 🧭 React Router DOM
- 🧠 JavaScript (ES6+)
- 🎨 CSS (single simple CSS file for the entire project)
- 🧩 React Hooks:
  - useState
  - useEffect
  - useContext
- 🎨 Figma (initial design)
- 🧩 Iconify (icons)
- 🤖 Gemini AI (image generation)
- 🌳 Git & GitHub

---

## 🎨 Design & UI

- Initial UI designed using Figma
- Light retouches and adjustments compared to the original Figma design
- Usage of a dynamic and modern font
- Navbar built manually without any library
- Clean UI built with plain CSS
- Fully responsive for mobile devices
- ❌ Tablet support not implemented yet (planned for future updates)

---

## 🎬 Animations & Visuals

- Custom animations used across the website
- Tom & Jerry characters used instead of real people images
- All images:
  - Generated using Gemini AI
  - In WEBP format
  - With transparent backgrounds

---

## 🧠 State Management & Logic

- State handled mainly with useState
- Shared state managed via useContext
- Side effects handled using useEffect
- No external state management libraries used
- Focus on simplicity, clarity, and maintainability

---

## 💾 Local Storage

- Local Storage is used to persist application data
- AI-assisted logic used to optimize data storage and retrieval

---

## 🔒 Business Rules & Constraints

- ❌ The same product cannot be purchased more than once
- ✅ Product duplication is checked before adding
- ⚠️ Simple and effective validation logic

---

## 🧭 Routing

- Navigation implemented using React Router DOM
- Smooth page transitions
- Navbar connected to routes without third-party libraries
